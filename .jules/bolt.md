## 2026-06-24 - [Hoisting expensive O(N) operations out of JSX Body and Loops]
**Learning:** The React app previously contained computationally expensive constant calculations including `new Date()` parsing, `.toLowerCase()`, and `Intl.DateTimeFormat` instantiation inside large `.filter()` array methods or placed reductions directly inside the JSX render body. This is a noticeable anti-pattern as it needlessly re-executes on every re-render and every loop tick.
**Action:** Always eagerly hoist expensive constant date string parsing, string operations, and Date formatting instantiation OUTSIDE of large O(n) array loops. Furthermore, always wrap these derived lists with `useMemo` if they rely on large data, and never execute O(n) manipulations inline directly within the JSX render body.
