## 2024-05-18 - Hoist Expensive Operations Out of Loops and Renders
**Learning:** Performing `new Date().getTime()`, `toLowerCase()`, or using `Intl.DateTimeFormat` inside large array methods (like `.filter()`, `.map()`, or `.forEach()`) or directly within JSX bodies creates unnecessary O(n) re-calculations on every render. Chained array methods inside JSX loops also create intermediate array allocations that cause UI jank.
**Action:** Always hoist constants outside the array loops (e.g. `const q = searchQuery ? searchQuery.toLowerCase() : '';`), consolidate multi-step `.filter().map().reduce()` logic into a single `for...of`/`for...in` pass, and compute complex derived values inside a single `useMemo` block rather than placing reductions directly inside the JSX render tree.
