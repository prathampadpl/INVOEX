
## 2024-06-20 - Hoisting Constants and Leveraging useMemo
**Learning:** This codebase frequently performs `O(N)` loop operations inside JSX renders or performs expensive O(1) mathematical evaluations (like `.toLowerCase()` or `new Date()`) inside `.filter()` operations over large arrays. Attempting to optimize these arrays by extracting calculations introduces potential regressions if conditionals that omit data (like `if (inv.vendorName)`) are accidentally wrapped around global accumulators (like `totalConfidenceScores`). Also, optimizations must include inline documentation to be considered "complete".
**Action:** Always aggressively hoist constants outside loops and wrap derived logic in `useMemo`. When rewriting aggregations, ensure that metric collection remains separate from display-level conditionals (e.g., aggregate score from *all* items, even if missing a `vendorName`, if that's what the application expects). Always add comments to modifications explicitly marked with "⚡ Bolt: [explanation]".
