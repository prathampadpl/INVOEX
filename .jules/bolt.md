## 2024-06-25 - Redundant computations in filter/forEach loops and inline JSX operations
**Learning:** Found multiple instances where constant computations (e.g. `searchQuery.toLowerCase()`, `new Date(filterStartDate).getTime()`, and `new Intl.DateTimeFormat`) were executed inside large O(N) array iteration hooks (`.filter`, `.forEach`). Additionally, chained array operations (`.filter().map().reduce()`) were used inside `.forEach` and directly within JSX blocks to compute averages on optional object fields, causing unnecessary array allocations per render.
**Action:** Always hoist invariant variable transformations outside loops. Condense sequential array iterations (`.filter().map().reduce()`) into a single `for...of` loop to prevent excessive intermediate allocations. Memoize expensive operations spanning whole object lists out of the JSX render body and into `useMemo`.
