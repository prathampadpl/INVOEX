## 2023-10-27 - Hoisting O(N) array method reductions from render
**Learning:** Found an anti-pattern in `src/pages/Dashboard.tsx` where chained `.filter().map().reduce()` logic for calculating things like confidence scores and overall metrics were being called inside loops or directly inside the JSX component render body. Furthermore, calculations like `searchQuery.toLowerCase()` and `new Date(filterStartDate).getTime()` were not hoisted from inside `.filter()` iterations, causing severe redundant recalculations on every single re-render.
**Action:** Always aggressively extract O(N) reductions out of JSX and into `useMemo` blocks using single `for` loops. Any constant such as `new Intl.DateTimeFormat()` or `.toLowerCase()` inside an array method must be instantiated or assigned outside of the array method.
