## 2024-06-21 - Hoisting expensive formatting and avoiding nested loops in render
**Learning:** Found an anti-pattern in the codebase where expensive formatting (`new Date().toLocaleDateString`) and constant values (`searchQuery.toLowerCase()`) were evaluated inside `.filter()` and `.forEach()` array methods on lists. Furthermore, a highly unoptimized mapping and `.reduce()` logic (`flatMap` over all scores) for the Avg Confidence metric was computed dynamically inside the JSX render loop, causing O(N) recalculations on every re-render (which could lead to UI jank).
**Action:** When working on array loops/JSX lists, constantly search for and aggressively hoist static string formatting, date parsing, or array `.reduce` accumulations into `useMemo` blocks or variable declarations outside loops. Instantiate `Intl.DateTimeFormat` outside of iteration loops to avoid redundant instantiations.
