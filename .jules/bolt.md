## 2024-06-14 - Constant evaluation in filter loops & inline render reductions
**Learning:** O(N) Array reductions (`filter()`, `flatMap()`) are frequently written directly inside the JSX return statement (e.g. `src/pages/Dashboard.tsx`). This causes massive CPU spikes on every re-render (which can happen frequently on keystrokes in search/filter). Additionally, constant calculations like string lowercasing and Date parsing are placed inside `filter` callbacks rather than hoisted outside, resulting in redundant O(N) operations.
**Action:** When working on components that render lists, ensure that constant expressions in search/filter loops are hoisted outside of the loop. Always lift complex aggregate operations (like filtering items, mapping nested arrays, computing averages) out of the JSX render and into a `useMemo` hook, combining it with existing `useMemo` hooks if possible.
