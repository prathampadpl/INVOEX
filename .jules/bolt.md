## 2025-02-12 - Prevented O(N) array reductions in JSX render block
**Learning:** Found an anti-pattern in `src/pages/Dashboard.tsx` where `.flatMap()`, `.filter()`, and `.reduce()` were executed inside a self-executing function right in the JSX render body (`Overall Avg Confidence` metric). This triggered full O(N) calculations across all invoices *every single time* the component re-rendered (such as on hover, input change, etc.), causing completely unnecessary CPU load. Furthermore, loop-invariant operations like string `.toLowerCase()` and `new Date().getTime()` were inside a long `.filter()` array map.
**Action:** Always extract complex Array iteration computations (e.g., reductions, calculations) into existing `useMemo` blocks to memoize the value across re-renders, and ensure invariant statements are hoisted to the top. This significantly improves performance and maintains linear time for these views rather than quadratic combinations across React lifecycles.
