## 2024-05-25 - React Component Array Parsing Bottlenecks
**Learning:** In heavy dashboards (like `src/pages/Dashboard.tsx`) that iterate over large local arrays using `useMemo`, doing string formatting operations (like `new Date(...).toLocaleDateString`) or repeated query lowercasing inside the `.filter` and `.forEach` blocks causes massive slowdowns on high volume rendering. In JS, instantiating an `Intl.DateTimeFormat` or running `Date.toLocaleDateString` repeatedly in a loop is notoriously slow.
**Action:** Always hoist invariant expressions (like start/end timestamp conversion, or query lowercase formatting) outside of filter loops. For repetitive date formatting, cache a single instance of `new Intl.DateTimeFormat()` before the loop and call `.format(timestamp)` inside the loop, rather than using `new Date(timestamp).toLocaleDateString()`.
