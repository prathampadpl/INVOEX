## 2025-06-09 - Avoid O(N) Reductions in JSX & Hoist Constants
**Learning:** Found multiple instances where large arrays were mapped or filtered directly inside the JSX render body (e.g., `invoices.filter(i => i.status === 'Approved').length`). Also discovered constant date parsing (`new Date()`) and string operations (`toLowerCase()`) happening inside loop iterators (e.g., `invoices.filter(inv => inv.vendorName?.toLowerCase().includes(query.toLowerCase()))`). This blocks the main thread during render, scales poorly as the data grows, and drops frames in React.
**Action:** Always pre-compute and memoize expensive aggregations, derived metrics, and filtered subsets outside of the JSX block using `useMemo`. For calculations involving multiple derivations from the same array, try to compute them in a single pass. Also, always hoist loop-invariant values outside the loop callback before filtering or mapping over long arrays.
