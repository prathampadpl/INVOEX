## 2025-03-02 - [Dashboard Component Render Bottleneck]
**Learning:** Inside `useMemo` hooks, operations like `new Date(string).getTime()` and `String.prototype.toLowerCase()` inside `.filter()` and `.map()` iterators are re-evaluated on every loop tick. Similarly, computing complex aggregations within the main render body via Array manipulations (e.g. `flatMap`, `reduce`) causes expensive operations to fire on every render cycle without being memoized.
**Action:** Always hoist non-varying logic (e.g., date parsing string timestamps, lowering search query input) outside of list iteration loops. Fast string formats via `Intl.DateTimeFormat` are significantly quicker than repetitively invoking `Date.prototype.toLocaleDateString()` inside loops. Also, heavy aggregations over lists should be memoized alongside related list iterations rather than kept separate in the main render thread.
